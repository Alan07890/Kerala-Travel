KERALA TRAVELOGUE — COMPLETE REDESIGN
=====================================

HOW TO OPEN
1. Extract the ZIP file (or open the folder).
2. Double-click index.html, or open the folder in VS Code and use Live Server.
3. The homepage introduces Idukki as the first chapter. Choose any district card to explore the other chapters.

WHAT CHANGED (COMPLETE VISUAL REDESIGN)
- Entirely new design system and layout — the site now looks completely different.
- New modern, airy, vibrant aesthetic (teal + coral accents on clean whites).
- New typography: Syne (display) + Inter (body).
- Completely rewritten CSS with a fresh component language.
- Improved responsive behaviour across desktop, tablet and mobile.
- Floating glass-style header, modern pill navigation, rounded cards.
- New hero treatment, stats layout, experience cards and culture section.
- District pages updated to match the new visual language.
- All original content, search, hotels filter and district chapters preserved.

WHAT IS INCLUDED
- Kerala travelogue homepage with Idukki as the main destination.
- All 14 district chapters, with Idukki listed first.
- District-specific places, food, activities, culture, lifestyle and travel tips.
- Searchable district cards, hotel directory with star filter, responsive layouts.
- Photo galleries and previous/next chapter navigation.

TECHNOLOGY
HTML5, CSS3 and vanilla JavaScript. No backend or database required.

IMAGES
Photographs load from Wikimedia Commons and require an internet connection. Each image retains its respective Creative Commons/public-domain licence.

CUSTOMISATION
- District content and image URL pools: js/data.js
- Homepage behaviour: js/main.js
- District page rendering: js/district.js
- Styling: css/style.css
